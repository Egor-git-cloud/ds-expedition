# Конкурсный запуск

`python inference/main.py INPUT_DIR OUTPUT_FILE` вызывает исходный бейзлайн через наш адаптер. Второй аргумент — файл GeoJSON. По умолчанию веса ожидаются в `models/baseline.pt`; доступны `--weights` и `--config`.

Обрабатываются все территории переданного входа. Локальное разбиение здесь не применяется. Это код первого решения, но реальный инференс и запуск на платформе ещё не проверены. Требуются зависимости бейзлайна и веса. Подробности в `docs/workflow.md`.
