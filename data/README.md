# Данные (локально)

Содержимое этой папки, кроме README.md, исключено из Git.

- `raw/train-koz-3/` — стандартный путь к исходному датасету. Можно использовать внешнюю папку через конфигурацию.
- `manifests/` — генерируемые каталоги файлов и сводки. Могут содержать личные абсолютные пути.
- `processed/` — будущие производные растры и тайлы.

Переносить исходный датасет сюда необязательно. Маленькие общие списки территорий для будущих экспериментов следует хранить в `configs/splits/`, чтобы они попадали в Git.
