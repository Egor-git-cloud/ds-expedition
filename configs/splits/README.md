# Общие разбиения

Используйте `v1.json` из общего коммита. `policy.json` содержит seed, доли и правила группировки. Не создавайте персональное случайное разбиение.

Версия v1 предварительная: группировка по именам ещё требует пространственной проверки. Правила, ограничения геофизики и команды — в `docs/workflow.md`.
