# Общий каталог

`files.csv` — снимок метаданных 1380 файлов из ранее созданного inventory. Он нужен для одинакового выбора территорий и оценки объёма без чтения LAS/GeoTIFF. Число объектов, геометрия и доступность файлов локально из этого каталога неизвестны.

Обновление: `python scripts/export_catalog.py` читает локальный `data/manifests/inventory.csv`, а не исходный датасет. После обновления пересмотреть split вместе с командой.
