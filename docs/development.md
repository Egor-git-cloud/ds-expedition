# Работа команды

- Основной код добавляем в `src/ds_expedition/`. По мере реализации создаём модули подготовки данных, обучения, инференса и обработки геометрии.
- `scripts/` содержит короткие точки запуска. Общая логика импортируется из пакета.
- Оригиналы организаторов храним в `vendor/organizer/` без изменений. Наши изменения алгоритма делаем в собственном коде.
- Зависимости фиксируем в `pyproject.toml` по мере появления компонентов. Сейчас каркас не требует ML/GIS-библиотек.
- Пути получаем через `load_paths()`. Чтение настроек не создаёт папки и не открывает датасет.
- Эксперименты должны ссылаться на конфигурацию, разбиение, версию кода и происхождение весов. Большие результаты сохраняем вне Git.
- Для изменения используем отдельную ветку и осмысленный коммит. Общие настройки не должны содержать пути конкретного компьютера или ключи доступа.

## Следующие этапы

1. Согласовать оборудование и доступность данных.
2. Проверить аннотации и геопривязку, уточнить предварительное разбиение v1 по территориям.
3. Воспроизвести бейзлайн и локальный расчёт метрики.
4. Реализовать подготовку данных и обучение.
5. Проверить адаптер `inference/main.py` на реальном входе и подготовить упаковку для платформы.

На этапе организации структуры эти вычисления не запускаются.
