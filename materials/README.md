# Материалы конкурса (локально)

Здесь хранятся исходные PDF, скриншоты, примеры GeoJSON и заметки. Содержимое исключено из Git, кроме этого описания.

Каждый участник получает материалы у организаторов: технический регламент, описание классов, пример выходного GeoJSON и архивы решений. Исходный код примеров находится в `vendor/organizer/`.
