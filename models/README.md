# Веса моделей (локально)

Веса исключены из Git. Для каждого эксперимента в будущем сохраняем происхождение весов, контрольную сумму и настройки в документации или конфигурации, а сам файл передаём отдельно.

Оригинальные веса бейзлайна сейчас находятся в `vendor/organizer/baseline_solution/model.pt` на рабочем компьютере. После клонирования их нужно получить из архива организаторов и положить рядом с исходным `solution.py`, если требуется запуск этого примера.
